# Sotto: Dictation — Releases

Direct-download builds of **Sotto**, a private, on-device push-to-talk
dictation app for Mac. Hold a key, speak, release — your words appear
wherever your cursor is. No account, no subscription, free.

This repo holds nothing but signed, notarized release DMGs — no source code.

- **Download**: see the [Releases](../../releases) page for the latest `.dmg`.
- **Also available on the Mac App Store**: [Sotto: Dictation](https://apps.apple.com/app/sotto-dictation/id6811554928?mt=12)
- **Website**: https://sotto.tortugas.site/
- **Support**: https://sotto.tortugas.site/support.html
- **Privacy Policy**: https://sotto.tortugas.site/privacy.html

## Installing

1. Download the `.dmg` from the latest release.
2. Open it, drag **Sotto** into **Applications**.
3. Launch Sotto from Applications. The first time you hold the dictation
   shortcut (default: Option+Space), macOS will ask for microphone access —
   grant it.

The app is signed with a Developer ID certificate and notarized by Apple, so
Gatekeeper will show the normal "Apple checked this app for malicious
software" dialog on first launch — not a "can't be opened" warning.
